      這個版本

      App 打不開時，不要刪除 App。

      免費 Apple ID 安裝的 App 大約 7 天會到期。到期後資料都還在，只要把 iPhone 接上 Mac 重新安裝（npm run ios:install），紀錄和照片都會保留。刪除 App 會連同所有紀錄一起刪掉。

      Obsidian vault

      尚未選擇

      選項清單

      名稱含「全麥」或「黑麥」算雜糧，含「T65」「T55」或「法國」算法國粉，含「高筋」算高筋，用來判斷配方分類。

      常用材料

      在「其他材料」輸入這些名稱時，會自動帶入分類與是否計入粉量、水量。

      匯出與備份

      匯出到 Obsidian

      每筆一篇 Markdown，加上照片、總覽與總表 CSV，打包成 zip。

      總表 CSV

      欄位和儀表板一致，可用 Excel 打開。

      完整備份（含照片）

      所有紀錄、照片與設定。iPhone 匯出後用 AirDrop 傳到 Mac 匯入。

      從備份匯入

      完整備份 zip，或舊版的 JSON 備份。同一筆以修改時間較新的為準，匯入前會先確認。

      自動備份

      升級前與第一次同步前，會自動建立一份完整備份（含照片）。

      匯入舊版照片

      先匯入舊版 JSON 備份，再選舊版「匯出到 Obsidian」的 zip，照片會依檔名對回紀錄。
